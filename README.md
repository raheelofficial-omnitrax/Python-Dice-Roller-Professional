# 🌟 About The Project

**Python Dice Roller Professional** is an upgraded command-line dice application built with Python.

The project started as a simple random dice generator and was improved into a complete mini-application with clean structure, reusable functions, and a better user experience.

The goal of this project is to practice Python programming concepts while creating a practical and enjoyable application.

---

# ✨ Features

## 🎲 Multiple Dice Rolling

* Roll one or many dice at the same time
* Generate random values from 1 to 6
* Display each dice using ASCII graphics

## 🖥️ Beautiful Terminal Graphics

The project uses custom ASCII art to represent dice faces.

Example:

```
┌─────────┐
│ ●     ● │
│    ●    │
│ ●     ● │
└─────────┘
```

## 🧮 Automatic Score Calculation

The program automatically calculates:

* Individual dice values
* Total score
* Number of dice rolled

Example:

```
Dice Values: [4, 2, 6]

Total Score: 12
```

## 🛡️ Input Validation

The program safely handles incorrect inputs:

✅ Prevents crashes
✅ Checks valid numbers
✅ Provides helpful error messages

## 🔄 Replay System

Players can continue rolling dice without restarting the program.
